= Creating Items =============================================

Steps to creating items for the inventory system:

1) Create an new itemData (ScriptableObject) asset in your project files that'll 
   represent the new item template. This asset defines and represents all 
   instances of the item. Changing an itemData changes all instances of the item,
   and all created items refer back to their itemData for their data
   [Right-Click -> Create -> Item Data]


2) Fill out the itemData. Here's a quick review of the itemData's fields:
   ---------------------------------------------------------------------------------------------------------------
   Name: The item's name that'll be shown in grids.
   ItemCode: The item's UNIQUE string identifier. This is how items are compared for equivalence.
             Make sure no 2 items share the same itemcode.
   Spacial Definition: If you were to draw the item on a grid, what cells would the item occupy
                       [starting at (0,0)]. Duplicate entries are ignored. This defines how many cells the item occupies
                       on the grid. Every entry represents a cell
   Item Handle: Where should the item be grabbed from and rotated around. This doesn't have to be the center,
                nor does it have to exist within the spacial definition. This is an important field that define's
                how the user and grid interacts with the item.
   Desc: item description
   Sprite: item sprite
   stackLimit: How many of this item can be packed together into the same grid space
   value: What's the baseline price of the item
   ---------------------------------------------------------------------------------------------------------------
   Audio Cues are self explanatory
   ---------------------------------------------------------------------------------------------------------------
   Ui Options:
   Is useable: Is this object useable from the inventory?
   Is Bulk Use Enabled: Can many of this item be used at once?
   Is Discardable: Can this item be discarded from the inv?
   Is Organizeable: Can this item be organized within the inv?
   Is Sellable: CAn this item be sold to merchants?
   ===============================================================================================================

   //Note:
   These fields may seem "set-in-stone", but they're not. It's intended that each user tailors this system to suit their
   needs-- if you want to add more fields then you're more than welcomed to do so. 
   The entire demo scene was built by myself as a demonstration ^_^



3) Draw the item's sprite:
   Default cell size for the premade vertical inventory window is 32x32 pixels.
   That can be changed in the grid object's grid component.
   If you want objects to span multiple cells (have taller or wider or larger items),
   then resize your canvas to match the item's total size from the start.
   Ex: Cube sprites are drawn in a 32x32 (1x1) pixel canvas, Boards are drawn in a 128x32 canvas (4x1),
       and "Things" (that's what they're called) are drawn in a 32x64 (1x2) canvas.
       The Hollow is a (3x3) item. Can you infer that item's original canvas size? 
   Item size formula: canvas dimensions = cellWidth * cellSize , cellHeight * cellSize  [where cellSize is your grid's defined cell size]

4) More about item handles:
   Items are placed, picked up, and rotated by their item handle. When creating an item, you'll need to
   specify an item handle so the system knows how to pick it up and rotate it. As stated above, the item's 
   handle doesn't necessarily need to exist within the item's spacial definition (useful for wheels and such).
   This is demonstrated with the "hollow" item.

5) Selecting/creating Ui Options for your items:
   I created some prebuilt ui Options for the demo's sake. These define what contexts the item may be used in.
   In your own project, you may wish to have different contexts, and that's expected. But It'll be up to you to
   handle those cases as well.

   Feel free to reach out to me regarding questions on about your implementation ideas (or how I implemented mine).
   I'm no super expert or anything, but I could offer advice or help write out a system for you.


6) Test creating the item:
   If you open the demo scene and select the Game Utilities gameObject [Demo Game > Quick Setup > Game Utilities],
   There's a script component called "Debug Spawn Item". 
   Set the specific item to your item (and amount to whatever amount you'd like to spawn) and then enter playmode.
   A batch of your specified items will bp spawned into the player's inventory when you click the "Spawn Item" bool
   in this script. Use this to help debug you item ideas.

7+) The Next Steps:
    Creating the items is just the first step. You probably also want to design your own inventories screens, navigation system,
    and item interaction mechanics too, right? I did, and I think you should definitely go for it! Everything build here is meant to 
    inspire you and help you along the way to build what you want for your own project. Feel free to use the demo to help you
    learn how to implement your own systems and tools.

    And of course, if you need help or if theres a bug or anything, reach out to me!
