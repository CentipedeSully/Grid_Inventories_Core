Designing Grid Uis

- How to approach designing Grid UIs
---------------------------------------

The InvGrid was designed to be a subElement for a larger UI system;
Embed it into your own Ui to suit your vision. 

This system isn't meant to be served to a user raw. You may want, for example, window
management buttons and labels (at the very minimum).


The package comes prepackaged with a Pointer-based interaction utility referred to as the
'GridInteracter', when reads input from the prepackaged 'InputDriver' script.

It's expected that you'll be using your own input method for your project, so (assuming you'll
use the prepackaged GridInteracter to start with) the GridInteracter was designed separately
from the InputDriver. Simply hook up your own input methods to the interacter and you have your
own custom GridInteracter working.
